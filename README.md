# TapTether

**Your devices. Your control. Your network.**

This public repository distributes the latest TapTether app and desktop agent installers. Development source code, build tools, and GitHub Actions workflows are kept in a separate private repository.

## Downloads

- [Latest TapTether release (IPA, APK, and desktop agents)](https://github.com/ssnanda/taptether.com/releases/tag/current)
- [AltStore source](https://raw.githubusercontent.com/ssnanda/taptether.com/main/altstore.json) (available after the first successful release)

The iOS IPA is unsigned and requires a compatible signing or sideloading method such as AltStore. Use only devices you own or are authorized to control; TapTether's computer remote communicates on the local network.

The **current** release and any platform-specific **ubuntu-current**, **macos-current**, or **windows-current** releases contain only their newest available artifacts. Older versions are not retained here.
